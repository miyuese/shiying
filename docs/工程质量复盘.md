## 二、致命问题修复（核心链路）

### 1. 参考图通道前后台不一致 → 参考图被静默丢弃

**症状**：换脸/重绘/拍一套等「带参考图生成」的功能，生成结果与参考图无关，等同随机文生图；且任务状态显示「已完成」，无任何报错，极具迷惑性。

**根因**：后台执行器只读 `sourceBlobKey / faceBlobKey`（IndexedDB 取货单），从不读 `sourceRef / faceRef`（dataURL 照片副本）；而前台各视图发的都是照片副本。前后台各用一半，接不上。

**修复**：统一为 blobKey 通道——后台收到 `sourceRef/faceRef` dataURL 后先 `toBlob` 存入 IndexedDB 再走 blobKey，两端对齐。

**沉淀**：消息协议中「二选一」的字段必须保证两端实现一致；图片传输统一走「落盘 → 引用」而非直传大字符串。

### 2. 图片压缩依赖 DOM API → 后台必然报错

**症状**：网页取图 / 上传 / 网页收集全失败，只剩相册选图可用。

**根因**：`compressImage` 内部用 `new Image()` + `canvas`，这些 API 只存在于浏览器页面环境；后台（Service Worker）调用即抛 `ReferenceError`，且调用方用 `catch {}` 静默吞错，用户只见「图没进来」。

**修复**：压缩逻辑改为 SW 安全实现（`createImageBitmap` + `OffscreenCanvas`），不依赖 `window/document`。

**沉淀**：MV3 后台代码禁止使用页面环境 API；吞错必须有日志与用户可见反馈，杜绝「静默失败」。

### 3.（连带 2）拼图法 fallback 同样用 canvas

**症状**：服务商不支持多图上传时，自动降级「拼图法」路径同样静默失败。

**根因**：与问题 2 同源——拼图合成用 `new Image()` + canvas。

**修复**：同步改造为 SW 安全实现，降级路径与主路径同等保障。

## 三、高优先级问题修复（功能被卡死）

### 4. 「纯反推」按钮无绑定 + 自动选卡无法清除

**症状**：想「不带人脸」生成永远做不到，界面有按钮、有说明，点了没反应。

**根因**：按钮渲染了但未绑定任何 click 事件；`selectedCardId` 为空时自动选中默认卡，用户无「清空选择」入口。

**修复**：移除「纯反推」按钮，人脸参考改为必选，消除语义歧义；并同步修正了「未选卡时提示词仍包含人脸参考说明」的连带问题（原问题 16）。

### 5. 默认生图模型名非法，开箱即 404

**症状**：新用户填好 API Key 直接生成 → AI 返回「模型不存在」。

**根因**：默认模型名与公开可用的模型名不一致。

**修复**：修正为真实模型名，模型选项支持自定义输入 + 常用列表。

## 四、中优先级问题修复（明显不可用）

### 6. 「取消任务」是空操作

**症状**：点取消 → 界面显示「已取消」，但任务照跑，跑完还会被改回「完成」。

**根因**：`cancelTask` 只改状态字段，全程没有任何 `AbortController` / 中断信号，HTTP 请求照发。

**修复**：补齐 AbortController，并在 `runGenerate` / provider 层透传中断信号；前端取消后任务真实中断。

### 7. 网页「影」按钮永远打开浮动窗口

**症状**：从网页点「影」总是弹出小窗口，而不是 Chrome 右侧侧边栏。

**根因**：`chrome.sidePanel.open` 要求用户手势，经 background 转发后手势丢失，必然走兜底分支。

**修复**：popup 路径直接调用 `chrome.sidePanel.open`（保留手势）正常开侧边栏；网页路径保留独立窗口兜底并明确提示。

## 五、低优先级项（已修 / 打磨清单）

**已修复**：
- 结果区「再生成」接入真逻辑：源图/人脸图落盘为持久 blob，以 blobKey 引用重新提交；配 GC 只保留最近 10 个任务的再生成输入图（含孤儿 blob 清理）

## 六、沉淀的工程实践

1. **参考图通道统一**：图片传输一律「落盘 → blobKey 引用」，不直传 dataURL。
2. **SW 安全约束**：后台代码禁止页面环境 API（canvas / `new Image()`），统一 `createImageBitmap` + `OffscreenCanvas`。
3. **超时与中断**：任务硬截止时间戳 + watchdog（chrome.alarms）周期回收 + AbortController 真实中断，杜绝「沉默卡死」。
4. **失败可见**：任何错误必须有日志与用户可见文案，禁止 `catch {}` 静默吞错。
5. **存储分层**：storage.local 只存小元数据（设置/引用），图片 blob 一律 IndexedDB；写库前 sanitize 剔除敏感字段。

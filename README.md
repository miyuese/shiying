# 拾影 ShiYing · Chrome 扩展（MV3）

> 网页图片 AI 工具：反推提示词 × 换脸 × 双参考重绘 × 拍一套 × 本地素材库
> 原生 TypeScript + Vite 构建，零运行时第三方依赖

## 功能特性

- **反推提示词**：选一张网页图片，AI 生成可编辑的提示词
- **双参考重绘**：构图参考图 + 人物卡人脸参考，重绘新图（画质自选 1K / 2K / 4K）
- **换脸**：源图场景、姿态、光线全保留，仅替换面部身份
- **拍一套**：一张方图生成 2×2 四宫格，本地自动切分为 4 张单图（固定 1:1 画幅，保证每格构图完整）
- **人物卡**：上传 1~4 张照片，生成标准三视图身份卡；同一时间只允许一张人物卡生成（互斥锁，杜绝任务归属混乱）
- **本地素材库**：悬停网页图片即可收集，生成结果自动回填，全部存储于本地

> **隐私**：所有 AI 调用均使用你自行配置的 API 密钥，密钥仅保存在浏览器本地存储，**源码不含任何密钥**。

## 生成进度

重绘 / 换脸 / 拍一套三个页面提交后**就地显示生成进度**（排队中 → 生成中百分比 → 完成 / 失败），用户无需离开当前页即可确认任务已启动，避免重复提交；生成超时（7 分钟预算）会明确失败并提示重试，绝不"沉默卡死"。

## 开发

```bash
npm install
npm run dev          # 监听构建
npm run build        # 类型检查 + 生产构建
npm test             # 单元测试
```

构建产物在 `dist/`。使用方式：Chrome 打开 `chrome://extensions` → 右上角开启「开发者模式」→「加载已解压的扩展程序」，选择 `dist/` 目录。

## 设计语言 · 暗房·电影感

- **近黑墨底 + 电蓝→紫渐变**：电影级的暗部与高光对比，图片为主角
- **胶片颗粒噪点**：全局 subtle 质感层，增强沉浸感
- **杂志式排版**：超大 display 字号、区块编号（01–05）、发丝线分隔、高字距 micro-label
- **Space Grotesk** 打包内嵌（仅 latin 子集，中文回退系统字体栈，离线可用）
- **Lucide 图标**：全站统一图标体系，禁用 emoji
- **动效**：流畅物理缓动，尊重系统 `prefers-reduced-motion`

设计令牌见 `src/shared/styles.css`。

## 可靠性设计（MV3 长任务）

Chrome MV3 的 Service Worker 是"用完即睡"的事件驱动进程，休眠会冻结计时器与网络回调。拾影的长任务采用**状态机 + 多级兜底**：

- 任务带**硬截止时间戳**（deadline），任何一端都能独立判定超时并强制结束
- **前端真实时钟兜底**：面板常驻、时钟永不冻结，超时即强制失败
- 后台 **watchdog**（chrome.alarms）周期唤醒，扫描并回收卡死任务
- **串行执行器** + 任务级硬超时，单任务卡死不堵队列
- 失败原因可见、可重试；超时自动重试 1 次（7 分钟总预算，按服务商实测耗时 ×2 设定）

## 提示词体系

- 反推方案：10 个内置方案（`src/shared/prompts.ts`），用户可在设置页选择
- 人物卡 / 换脸 / 拍一套：自研提示词模板，结合实际生成效果反复迭代
